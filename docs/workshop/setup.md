## Before we start

### Requirements 

To participate in this workshop, you will need: 

1. a text editor to write RDF in; and
2. a GitHub account. 

#### Text Editor

For this exercise, you will need a text editor. This is an application that allows you to write what is called 'plain text' -- text recorded purely as character sequences, without any formatting. This is different from word processing applications like MS Word, Libre Office Writer, or Mac's TextEdit, which allow you to format texts, while the plain text 'source code' of your writing is saved in the background.

Students in the Kontrollerade Vokabularer course will have been using o[oXygen](https://www.oxygenxml.com)Xygen to write XML and other plain text formats in the program, which is an excellent choice. Alternatives include the free applications[Visual Studio Code](http://vscode.com) or [Sublime Text](https://www.sublimetext.com).

If you do not yet have a text editor installed, you can also use a web version, like [Visual Studio Code's web editor](https://vscode.dev), or [codeshare](https://codeshare.io).

#### GitHub account

Towards the end of the workshop, you will be uploading your work into an existing GitHub repository. To do this, you will need a GitHub account. To make one, please visit [GitHub](https://github.com), pick a username you feel comfortable with, and register. While technically only one person per group will need to upload the group's work, students in the Kontrollerade Vokabularer course will also need an account for further courses in the programme, so it is best to already register now.

### More information about Linked Open Data

Students in the Kontrollerade Vokabularer course will already had a first introduction to Linked Open Data. Still, it can be useful to refresh your memory by watching this one-hour video lecture on [Linked (Open) Data for Libraries](https://hb.instructure.com/courses/12647/pages/linked-data-workshop) before the start of the workshop.
